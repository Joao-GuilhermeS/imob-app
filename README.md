# 🏡 App de Gestão Imobiliária

Este aplicativo transforma a jornada imobiliária ao conectar a autonomia do comprador à organização estratégica do vendedor. Através de uma plataforma ágil e sem burocracia, o cliente ganha independência para buscar propriedades, explorar lotes detalhadamente, agendar visitas e enviar propostas. Simultaneamente, o sistema fornece ao vendedor ferramentas precisas para gerenciar seu inventário e otimizar o atendimento em tempo real.

## 🚀 Arquitetura e Tecnologias

- **Backend:** Java / Kotlin 
- **Frontend/Mobile:** Android Studio / VS Code
- **Banco de Dados:** PostgreSQL

## 📦 Módulos Principais
1. **Visão do Comprador:** Busca interativa no mapa, filtros avançados, agendamento de visitas e envio de propostas.
2. **Visão do Vendedor (Corretor/Loteadora):** Gestão de inventário de lotes/imóveis, pipeline de vendas (Kanban) e gestão de leads.
